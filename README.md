# Визуализация графа зависимостей Rust-пакетов (Cargo)

**Дисциплина:** Конфигурационное управление  
**Вариант:** № 2  
**Язык реализации:** Python 3  
**Формат конфигурации:** XML

## Описание проекта

Консольное приложение для анализа зависимостей пакетов Rust (Cargo) и визуализации полученного графа. Программа настраивается через XML-файл. Реализация ведётся последовательно в пять этапов.

> **Важно:** готовые менеджеры пакетов и библиотеки для получения зависимостей не используются. Информация о зависимостях и разрешение SemVer-ограничений реализованы собственной логикой с использованием стандартных модулей Python (`xml.etree.ElementTree`, `urllib.request`, `json`).

**Текущий статус:** реализованы этапы 1–3 (конфигурация XML, сбор метаданных Cargo по HTTP, нерекурсивный обход транзитивного графа DFS, фильтрация по подстроке, обработка циклов и тестовый режим из файла).

## Этап 1. Минимальный прототип с конфигурацией

Параметры `config.xml`:

| Параметр | Назначение |
| --- | --- |
| `package_name` | Имя анализируемого пакета (`A-Z` в тестовом режиме) |
| `repository` | URL-адрес репозитория или путь к файлу тестового репозитория |
| `test_mode` | Включение режима тестового репозитория (`true` / `false`) |
| `package_version` | Версия пакета в формате SemVer |
| `output_file` | Имя выходного файла с изображением графа (`.svg`) |
| `ascii_tree` | Включение ASCII-дерева зависимостей (`true` / `false`) |
| `filter_substring` | Подстрока для исключения пакетов из анализа |

## Этап 2. Сбор данных

Модуль `src/cargo_repo.py` обращается к совместимому с `crates.io` HTTP API или sparse-индексу `index.crates.io`, извлекает обязательные зависимости секции `[dependencies]` (`kind = "normal"`, `optional = false`) и сопоставляет SemVer-требования (`^`, `~`, `>=`, `<=`, `=`, `*`) доступным релизам для построения транзитивных связей.

## Этап 3. Основные операции

Реализовано в модуле `src/dep_graph.py`:

1. **DFS без рекурсии:** обход выполняется на явном стеке с трёхцветной разметкой вершин (`0` — не посещена, `1` — в текущем пути стека, `2` — завершена), что исключает переполнение стека вызовов Python на глубоких графах.
2. **Фильтрация (`filter_substring`):** пакеты, имена которых содержат заданную непустую подстроку, игнорируются вместе с их подграфами.
3. **Обработка циклов:** переходы в вершины со статусом `1` фиксируются как обратные циклические рёбра (включая самозависимости вида `D -> D`) без зацикливания программы.
4. **Режим тестирования (`test_mode=true`):** граф считывается из локального файла формата `A: B, C`, где названия пакетов состоят из заглавных латинских букв (`^[A-Z]+$`).

### Коды ошибок приложения

| Код | Причина |
| --- | --- |
| `E01` | Файл конфигурации не найден или не читается |
| `E02` | Некорректный XML |
| `E03` | Отсутствующий параметр или некорректная структура XML |
| `E04` | Неверное имя пакета (или не `A-Z` при `test_mode=true`) |
| `E05` | Неверное булево значение (`test_mode`, `ascii_tree`) |
| `E06` | Некорректный URL или путь к тестовому файлу |
| `E07` | Неверный формат версии |
| `E08` | Неверное имя выходного SVG-файла |
| `E09` | Недопустимое значение фильтра |
| `E10` | Дублирование параметра в XML |
| `E11` | Пакет или подходящая версия не найдены в источнике |
| `E12` | Сетевая ошибка или ошибка HTTP при обращении к репозиторию |
| `E13` | Некорректный формат метаданных ответа репозитория |
| `E15` | Синтаксическая ошибка в файле тестового репозитория |

## Запуск и демонстрация Этапа 3

1. **Реальный пакет Cargo (`serde_derive 1.0.210`, транзитивный граф):**
   ```bash
   python src/main.py --config config.xml
   ```
   Вывод:
   ```text
   Граф зависимостей (корень: serde_derive):
     serde_derive -> proc-macro2, quote, syn
     proc-macro2 -> unicode-ident
     quote -> proc-macro2
     syn -> proc-macro2, quote, unicode-ident
     unicode-ident -> нет зависимостей
   ```

2. **Тестовый репозиторий с фильтрацией подстроки `B` (`examples/config-test.xml`):**
   ```bash
   python src/main.py --config examples/config-test.xml
   ```
   Вывод (ветка `B` и пакет `E` исключены фильтром, ромбовидный узел `D` достигнут через `C`):
   ```text
   Граф зависимостей (корень: A):
     A -> C
     C -> D, F
     D -> G
     F -> G
     G -> нет зависимостей
   ```

3. **Тестовый репозиторий с циклами (`examples/config-cycle.xml`):**
   ```bash
   python src/main.py --config examples/config-cycle.xml
   ```
   Вывод:
   ```text
   Граф зависимостей (корень: A):
     A -> B, D
     B -> C
     C -> A, E
     D -> D
     E -> нет зависимостей
   Обнаружены циклические зависимости: C -> A, D -> D
   ```

4. **Изолированная вершина без зависимостей (`examples/config-isolated.xml`):**
   ```bash
   python src/main.py --config examples/config-isolated.xml
   ```
   Вывод:
   ```text
   Граф зависимостей (корень: Z):
     Z -> нет зависимостей
   ```
